ABOUT SECURENOTES

Your thoughts belong to you.

SecureNotes is a privacy-focused notes application designed to help you write, organize, and protect personal thoughts without relying on a traditional backend.

🔐

Client-side encryption

Your notes are encrypted directly in the browser using the Web Crypto API before they are stored.

🛡️

Private by design

SecureNotes does not require a server, account system, or remote database to manage your notes.

💻

Works offline

Notes are stored locally in your browser, allowing the application to work without an internet connection.

⚙️

Simple technology

The application is built using HTML, CSS, and vanilla JavaScript, with no unnecessary frameworks or external services.

SECURITY MODEL

Designed to keep encryption close to you.

SecureNotes uses password-based key derivation and AES-GCM encryption through the browser's Web Crypto API. The encryption key is kept in memory while the application is unlocked and is not intentionally stored as plaintext in browser storage.
